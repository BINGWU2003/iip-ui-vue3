# 面试题学习建议

## 第一步：先分清"会说"和"会做"

这 26 道题分两类：

**A 类 — 「背后有真实代码」的题（最重要）**

这些你亲手写过，只需要把"当时怎么想的"整理成语言：

- Q13 DialogSelect 泛型设计
- Q14 FileListPreview 预览分层
- Q15 函数式调用实现
- Q19 RequestManager 竞态
- Q3 Turborepo 缓存（你写了 `turbo.json`）

**做法：** 对着代码复述，不看文档能说清楚思路就算过关。

**B 类 — 「概念性」的题（需要补充学习）**

- Q7 ESM/CJS 双输出的原理
- Q9 Tree-shaking 的条件
- Q24 manualChunks 策略

**做法：** 需要额外看资料，理解底层原理再关联到项目。

---

## 第二步：用「追问式」练习

面试官不会只问第一层，你需要练习被追问：

```
Q15 函数式调用
  └─ 追问：如果项目用了 Pinia，openFileListPreview 里要怎么处理？
        └─ 答：app.use(store) 同步安装，但拿到 store 实例需要从外部传入或用 provide

Q19 RequestManager
  └─ 追问：和 AbortController 有什么本质区别？能否结合使用？
        └─ 答：AbortController 取消网络请求本身，requestManager 只是丢弃结果...
```

**建议：** 找同学或者对着镜子，对每道题进行 2 轮追问练习。

---

## 第三步：建立「数字锚点」

面试时能说出具体数字，可信度大幅提升：

| 需要记住的数字                         | 来源                                                                         |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| 接入 **2 个 PC 端 + 3 个小程序**       | 简历数字，要说出来                                                           |
| 文件预览防抖 **300ms**                 | 代码里的真实值                                                               |
| 组件库版本 **1.2.x**，工具库 **1.2.x** | 体现持续迭代                                                                 |
| 封装了 **5 个**核心组件                | DateRange / PaginationSelect / DialogSelect / DropdownList / FileListPreview |

---

## 第四步：重点深入的 3 道题

这几道题是**高频且有深度差**的，建议重点准备：

**1. Q19 RequestManager（最有区分度）**

很多人知道竞态问题，但能用代码说清楚闭包 + 递增 ID 原理的不多。把这段代码背到能手写。

**2. Q7 双模块输出（最容易被追问）**

容易被追到"为什么 CJS 不能 Tree-shaking"、"`exports` 字段的优先级"，建议看一下 Node.js 文档的 Conditional Exports。

**3. Q25 项目推动落地（最体现软实力）**

面试官用这道题考察你的主观能动性，要有具体的故事：「当时遇到 XX 问题，我做了 XX，结果是 XX」，数据越具体越好。

---

## 第五步：准备一个「1 分钟项目介绍」

面试开场必问，建议按这个结构：

```
背景（1句）→ 解决了什么问题（1句）→ 你负责了什么（2-3个亮点）→ 结果（数字）
```

> 「这是我主导从零搭建的企业级 UI 组件库，解决了公司多个中后台项目组件重复建设的问题。
> 我负责了 Monorepo 架构搭建、核心组件封装（重点是弹窗选择和文件预览）、以及一个请求竞态管理模块。
> 目前已接入 2 个 PC 端和 3 个小程序项目，作为前端基础设施持续支撑新项目。」

---

## 总结

**先把 A 类题对着代码复述清楚，再补 B 类概念，最后练被追问。**

你有真实代码支撑，只要能把"当时怎么想的"说出来，就比背答案强很多。
